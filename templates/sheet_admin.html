Get your class list from Canvas

Keep this open while you click through Canvas in another tab. It takes about a minute.

Open Canvas ↗
  1. Open your course in Canvas.
  2. In the course menu on the left, click New Analytics (at some schools it's called Course Analytics, or it's a button on the course's home page). Don't see it? Go to Settings → Navigation, drag it up into the visible list, and click Save.
  3. Click the Reports tab, then Run Report next to Class Roster. If it asks about filters, just run it.
  4. A file like roster-2026-10-08.csv downloads. Drag it onto the box on this page — done.

Students missing? The course has to be published, and Canvas can take a day or two to add brand-new enrollments to this report.

Only have a gradebook export? (Grades → Export → Export Entire Gradebook.) That works too, but it usually has no email addresses, so students would sign in with their name and a PIN.

Not using Canvas? An Excel or CSV file with a “Name” column (and ideally “Email”) works — or paste the names in. Older Excel files (.xls) need saving as CSV first.

Afterwards, delete the downloaded file — it holds more than this site needs.
