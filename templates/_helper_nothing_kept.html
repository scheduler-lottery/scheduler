{# "Is any of this recorded?": what Scheduler Helper and this site keep from Canvas, for the curious, next to the helper wherever it's offered. Each line is true of the code (extension/background.js has no storage at all; teach._take_canvas_list keeps only names and emails). #}
Is any of this recorded?
  • Scheduler Helper keeps nothing. It has no storage at all: not your class list, not your course, not your Canvas sign-in. It reads Canvas only when you press Import class list here, hands the names and emails straight to this page, and forgets them. It sends nothing anywhere else.
  • {{ app_name }} keeps only the names and email addresses you add, so your students can sign in. Not the Canvas course, its number, grades, your Canvas sign-in, or anything else from Canvas. Delete the list or the sheet, and they go too (a deleted sheet can be brought back for 30 days, then it's gone for good).
  • So that updating the list later is one press, the browser on this computer remembers which Canvas course this sheet is for. {{ app_name }} doesn't.
  • Check for yourself: the helper's code, this site's code, and the privacy notes.
